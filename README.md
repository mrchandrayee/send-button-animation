A satisfying send button with paper-plane launch animation and delivery confirmation. Pure HTML, CSS & JavaScript.

---

## ✨ Features

- ✈️ Paper plane launch on send
- 📨 Idle → Sending → Sent states
- ✅ Delivery confirmation tick
- ✨ Smooth CSS animation
- ⚡ Zero dependencies
